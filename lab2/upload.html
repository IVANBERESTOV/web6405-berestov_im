Добро пожаловать!

File Server - HTML + CSS макет веб-сервиса загрузки файлов. Здесь можно загрузить свой файл, посмотреть список уже загруженных и узнать о проекте.

Загрузка файла

Выберите файл на вашем устройстве.

Возможности сервиса

  • Загрузка файлов любых форматов.
  • Скачивание загруженных ранее файлов.
  • Хранение файлов.

Посмотреть уже загруженные файлы можно на странице «Мои файлы».

Правила загрузки

  • Максимальный размер файла - 2 ГБ.
  • Разрешены любые расширения.
  • Файлы могут быть удалены без вашего ведома (и без моего тоже).
